- 软件简称：智能文档扫描识别软件
- 版本号：V1.0
- 需求概要分析待作者确认。

## 代码与架构事实

- 移动端位于 `mobile/`，采用 Flutter、Material 组件、HTTP 客户端、文件选择器和本地偏好设置。
- 服务端位于 `src/ds_ocr_runner/`，采用 FastAPI、SQLAlchemy 与 PostgreSQL。
- PostgreSQL 同时保存业务数据并通过 `FOR UPDATE SKIP LOCKED` 承担任务队列，不依赖 Redis。
- 文件上传后保存至服务端本地存储，并记录名称、类型、大小和 SHA-256 摘要。
- 任务状态包括 queued、running、succeeded、failed、canceled；任务记录包含重试次数、工作进程、锁定与完成时间。
- 识别结果包含纯文本、Markdown、版面信息和元数据。
- OCR执行层包含占位后端和可配置的 DeepSeek-OCR-2 独立进程后端；实际模型依赖在本次材料环境中未完成验证。
- 对外接口覆盖健康检查、文件上传/查询、任务创建/查询/取消和结果读取；内部接口供可信工作进程领取、完成或标记失败。

## 运行与测试事实

- Android 调试 APK 已生成并成功安装至 Android 16 虚拟终端。
